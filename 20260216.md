# Parity-Consistent Clifford Layer Assignment for Mirror Quantum Awesomeness

## Abstract

This document describes two modifications to `mirror_rb_experiment.py` that enforce a deterministic parity invariant on the outermost Clifford layer across all rounds of a Quantum Awesomeness (QA) experiment. The changes ensure that every odd-indexed round places a two-qubit (2q) Clifford layer at the circuit position where the entangling angle is injected, while every even-indexed round places a single-qubit (1q) layer. The fix applies to all three sampling algorithms (`edge_grab`, `matching`, `new`) and preserves the mirror circuit identity as defined in Proctor et al. [1, Supplementary Note 5].

**File modified:**

| File | Lines added | Purpose |
|---|---|---|
| `bench_code/mrb/mirror_rb_experiment.py` | 394--430 | Parity swap + sibling borrowing |

**References:**

- [1] Proctor et al., "Scalable Randomized Benchmarking of Quantum Computers Using Mirror Circuits" (arXiv: 2112.09853). Supplementary material: `Supplmrb.pdf`.
- [2] Amico et al., "Defining Standard Strategies for Quantum Benchmarks" (arXiv: 2204.07568).

## 1. Background

### 1.1 Mirror Circuit Structure

A randomised mirror circuit, as defined in [1, Supplementary Note 5, Section A], is constructed from a forward half of Clifford layers and a backward half where each layer is inverted:

> *"A width-w randomized mirror circuit with a benchmark depth of d consists of [...] the layers from step (c) in the reverse order with each Omega-random layer replaced with its inverse [and] each Pauli layer independently resampled."* --- [1, Supplementary Note 5]

In the codebase, the forward Clifford layers `C_0, C_1, ..., C_{k-1}` and their inverses are interleaved with random Pauli layers `P_i`. For a circuit with `k` Clifford layers, the full sequence has `4k + 1` elements (odd indices are Cliffords, even indices are Paulis):

```
P_0, C_0, P_1, C_1, P_2, ..., C_{k-1}, P_k, C_{k-1}^{-1}, P_{k+1}, ..., C_0^{-1}, P_{2k}
```

This is implemented at `mirror_rb_experiment.py:327-356`. The forward half is generated by the sampler (`_distribution()`, line 334--338), and the inverse half is appended by `_inverse_layer()` (line 348). Pauli layers are interleaved when `pauli_randomize=True` (line 351--356).

### 1.2 Truncation (`full_sampling=False`)

When `full_sampling` is off (line 310--311), only the longest circuit length is fully sampled. Shorter circuits are derived by symmetric truncation of the longest sequence:

```python
# mirror_rb_experiment.py:377-379
if not self.experiment_options.full_sampling:
    for real_length in build_seq_lengths:
        sequences.append(seq[: real_length // 2] + seq[-real_length // 2 :])
```

This means all circuits within a single sample share Clifford layers from the same parent sequence. For example, the length-10 circuit's layers are a strict subset of the length-50 circuit's layers. This is by design: it reduces sampling cost while maintaining that each layer was independently and randomly generated.

### 1.3 Clifford Reordering

When entangling angles are active (`any(self._angles)` is `True`, line 382), the Clifford layers are reordered so that the **deepest** (innermost) layer moves to index 1 --- the outermost position. This is where the entangling angle `theta` is injected as an `Rx(theta)` rotation before each CX gate (line 469--471 for the forward layer, line 485--487 for the inverse):

```python
# mirror_rb_experiment.py:493-495 (forward Clifford at index 1)
if l == 1 and instr.name == "cx":
    if self._angles[0]:
        circ.compose(qrx[0], [qargs[0]], inplace=True)

# mirror_rb_experiment.py:485-487 (inverse Clifford at index n-2)
if l == (len(seq) - 2) and instr.name == "cx":
    if self._angles[1]:
        circ.compose(qrx[1], [qargs[0]], inplace=True)
```

The reordering (line 382--392) reverses the Clifford order while keeping Pauli layers in place:

```python
# mirror_rb_experiment.py:382-392
if not self.experiment_options.full_sampling and any(self._angles):
    for s, sequence in enumerate(sequences):
        hsl = (len(sequence) - 1) // 2
        reordered_sequence = []
        for j in range(len(sequence)):
            h = j > hsl
            if j % 2:  # cliffords
                reordered_sequence.append(sequence[hsl - j - h])
            else:  # paulis
                reordered_sequence.append(sequence[j])
        sequences[s] = reordered_sequence
```

After reordering, the sequence becomes:

```
P_0, C_{k-1}, P_1, C_{k-2}, ..., C_0, P_k, C_0^{-1}, ..., C_{k-2}^{-1}, P_{2k-1}, C_{k-1}^{-1}, P_{2k}
```

The Clifford at index 1 is now `C_{k-1}` (the deepest layer), and its inverse is at index `n - 2` (where `n = len(sequence)`). These are the two positions where the entangling angle is injected.

### 1.4 The Three Sampling Algorithms

The codebase implements three sampling algorithms in `utilities/sampling_utils.py`, each with different approaches to two-qubit gate placement:

#### 1.4.1 `EdgeGrabSampler` (lines 260--482)

Selects edges via a random greedy algorithm (`_select_edges()`, line 342--360) and places 2q gates **probabilistically** on each selected edge:

```python
# sampling_utils.py:442-443
for edge in selected_edges:
    if self._rng.random() < two_qubit_prob:
```

where `two_qubit_prob = num_qubits * two_qubit_gate_density / 2 / len(selected_edges)` (line 425--427). Every layer has the same statistical distribution of 2q gates, but the exact count varies stochastically.

#### 1.4.2 `MatchingSampler` (lines 485--518)

Inherits from `EdgeGrabSampler` and uses a maximum-weight matching algorithm for edge selection (`_select_edges()` with `matching=True`, line 362--376). It uses the same probabilistic 2q gate placement as `EdgeGrabSampler`. Every layer has the same statistical distribution.

#### 1.4.3 `NewSampler` (lines 520--616)

Inherits from `MatchingSampler` but overrides `__call__()` with a strict **deterministic alternation**:

```python
# sampling_utils.py:583-614
for layer_idx in range(length):
    if (layer_idx % 2) == 0 or not two_qubit_gates:
        # Even layer: all single-qubit gates, no pairs
        ...
    else:
        # Odd layer: ALL matched edges get 2q gates (deterministic)
        selected_edges = self._select_edges()
        for edge in selected_edges:
            ...
            layer.append(GateInstruction(tuple(edge), gate))
```

- **Even layers** (0, 2, 4, ...): exclusively 1q gates.
- **Odd layers** (1, 3, 5, ...): every matched edge receives a 2q gate deterministically, producing a full matching.

This alternation is the source of the parity problem addressed by this fix.

## 2. Problem Statement

### 2.1 The Parity Inversion

After reordering, the outermost Clifford at index 1 is `C_{k-1}`, where `k` is the number of Clifford layers (equal to `circuit_length / 2`). Whether `C_{k-1}` was generated as an even layer (1q) or odd layer (2q) by `NewSampler` depends on the parity of `k - 1`:

| Circuit length | `k` = Clifford layers | Deepest layer index (`k - 1`) | Layer type |
|:-:|:-:|:-:|:-:|
| 2 | 1 | 0 | 1q (even) |
| 4 | 2 | 1 | 2q (odd) |
| 10 | 5 | 4 | 1q (even) |
| 20 | 10 | 9 | 2q (odd) |
| 50 | 25 | 24 | 1q (even) |

With `lengths = [2, 4, 10, 20, 50]`, each sample generates 5 rounds. Within one sample the alternation is (empty, full, empty, full, empty). But since the sample contains an odd number (5) of lengths, the pattern **inverts at every sample boundary**:

```
Sample 0:  round 0 (empty), 1 (full), 2 (empty), 3 (full), 4 (empty)
Sample 1:  round 5 (empty), 6 (full), 7 (empty), 8 (full), 9 (empty)
                    ↑↑ Two consecutive empties at boundary (rounds 4, 5)
```

This means the parity of a round's index `s` does not reliably predict whether its outermost Clifford has 2q gates.

### 2.2 Why This Matters for QA

In Quantum Awesomeness, the entangling angle `theta` is injected as `Rx(theta)` before each CX gate at the outermost Clifford positions (indices 1 and `n - 2`). If the outermost Clifford has no CX gates (1q-only layer), the entangling angle has no effect on that circuit, and the `_pairs` list is empty. The downstream `QuantumAwesomeness.mean_mutual_info()` computation groups data by whether qubit pairs were entangled or not. An unpredictable alternation pattern corrupts this grouping.

### 2.3 Scope

This problem is specific to `NewSampler` due to its deterministic even/odd alternation. For `EdgeGrabSampler` and `MatchingSampler`, every layer has the same probabilistic distribution of 2q gates, so the parity of the deepest layer index does not systematically determine its gate content. However, the fix is applied uniformly to all samplers for consistency (see Section 4).

## 3. Solution

Two blocks are added to `_sample_sequences()` after the existing reordering step (line 392) and before the `_pairs` extraction (line 432). Both blocks are guarded by `not self.experiment_options.full_sampling and any(self._angles)`, so they only activate for QA experiments with truncated sampling.

### 3.1 Block 1: Parity-Aware Swap (lines 394--406)

For each sequence with at least two Clifford layers (sequence length >= 9), this block swaps the Clifford layers at indices 1 and 3 (and their mirror counterparts at `n - 2` and `n - 4`) whenever the outermost layer's 2q content does not match the desired round parity.

```python
# mirror_rb_experiment.py:394-406
# Parity-aware swap: ensure outermost Clifford matches round parity
# (odd rounds -> 2q layer at index 1, even rounds -> 1q layer)
if not self.experiment_options.full_sampling and any(self._angles):
    for s, sequence in enumerate(sequences):
        if len(sequence) < 9:  # need at least 2 Clifford layers
            continue
        has_2q = any(len(g.qargs) == 2 for g in sequence[1])
        want_2q = (s % 2 == 1)
        if has_2q != want_2q:
            n = len(sequence)
            # Swap outermost pair of Cliffords (indices 1<->3 and mirror n-2<->n-4)
            sequence[1], sequence[3] = sequence[3], sequence[1]
            sequence[n - 2], sequence[n - 4] = sequence[n - 4], sequence[n - 2]
```

**Logic:**

1. `has_2q`: inspects the gate arguments of the Clifford layer currently at index 1.
2. `want_2q = (s % 2 == 1)`: odd round indices should have 2q gates.
3. If mismatched, swap indices `1 <-> 3` (forward) and `n-2 <-> n-4` (inverse).

### 3.2 Block 2: Sibling Layer Borrowing (lines 408--430)

Length-2 circuits have exactly one Clifford layer and no second layer to swap with. On odd rounds, this block borrows a 2q Clifford layer (and its inverse) from a sibling sequence in the same sample.

```python
# mirror_rb_experiment.py:408-430
# Handle length-2 circuits on odd rounds: borrow a 2q Clifford layer
# from a sibling sequence in the same sample. This is consistent with
# the truncation design where all lengths already share layers from the
# same parent sequence.
if not self.experiment_options.full_sampling and any(self._angles):
    num_lengths = len(self.experiment_options.lengths)
    for s, sequence in enumerate(sequences):
        if len(sequence) != 5 or s % 2 == 0:
            continue
        sample_start = (s // num_lengths) * num_lengths
        for sib_idx in range(sample_start, sample_start + num_lengths):
            sib = sequences[sib_idx]
            if len(sib) < 9:
                continue
            sn = len(sib)
            for fwd in (1, 3):
                if any(len(g.qargs) == 2 for g in sib[fwd]):
                    sequence[1] = sib[fwd]
                    sequence[3] = sib[sn - 1 - fwd]
                    break
            else:
                continue
            break
```

**Logic:**

1. Only targets length-2 sequences (`len(sequence) == 5`) on odd rounds (`s % 2 == 0` is skipped).
2. Finds the first sibling in the same sample that has a 2q layer at index 1 or 3.
3. Copies that layer and its mirror inverse into the length-2 sequence.

### 3.3 Downstream Code: No Changes Required

The `_pairs`/`_singles` extraction (line 432--442) and the entangling angle injection (line 485--495) both reference indices 1 and `n - 2`. Since the swap and borrowing ensure the correct layer type at those positions, no further modifications are needed.

## 4. Theoretical Justification

### 4.1 The Mirror Identity Under Reordering

A mirror circuit implements the identity (up to Pauli corrections) because the inverse half exactly undoes the forward half. The key invariant is that the Clifford at forward index `j` and the Clifford at inverse index `n - 1 - j` form a conjugate pair: `C_j * C_j^{-1} = I`.

**The swap preserves this invariant.** When we swap indices 1 and 3 in the forward half, we simultaneously swap indices `n - 2` and `n - 4` in the inverse half. After the swap:

- Index 1 (forward) and index `n - 2` (inverse) still form a conjugate pair.
- Index 3 (forward) and index `n - 4` (inverse) still form a conjugate pair.

**Concrete example** (length-10 circuit, 5 Clifford layers, sequence indices 0--20):

Before swap:
```
P0, C4, P1, C3, P2, C2, P3, C1, P4, C0, P5, C0^-1, P6, C1^-1, P7, C2^-1, P8, C3^-1, P9, C4^-1, P10
```

After swap (indices 1 <-> 3, and 19 <-> 17):
```
P0, C3, P1, C4, P2, C2, P3, C1, P4, C0, P5, C0^-1, P6, C1^-1, P7, C2^-1, P8, C4^-1, P9, C3^-1, P10
```

Forward product: `C3 * C4 * C2 * C1 * C0`
Inverse product: `C0^{-1} * C1^{-1} * C2^{-1} * C4^{-1} * C3^{-1}`

The inverse is the exact reverse composition of the forward, confirming the mirror identity holds.

### 4.2 The Borrowing Is Consistent with Truncation

When `full_sampling=False`, all circuits within a sample are derived from the same parent sequence. The length-4 circuit shares its Clifford layers with the length-10, length-20, and length-50 circuits. The borrowing operation adds one more shared layer for the length-2 circuit, which is fully consistent with this existing design.

For length-2, the sequence structure is `P0, C, P1, C^{-1}, P2`. Substituting `C` and `C^{-1}` with a borrowed pair from a sibling preserves `C * C^{-1} = I`. The Pauli layers `P0, P1, P2` are independently random and do not depend on the Clifford choice. The target bitstring is recomputed from the actual circuit at line 505 (`compute_target_bitstring(circ_target)`), so it correctly reflects the substituted layers.

### 4.3 Consistency with [1, Supplementary Note 5]

Proctor et al. define randomised mirror circuits using independently sampled Clifford layers drawn from a configurable distribution Omega:

> *"Our experiments used randomized mirror circuits built from alternating layers of randomized Pauli gates and Clifford gates chosen from a sampling distribution Omega over a Clifford layer set L_w."* --- [1, Supplementary Note 5, Section A]

The success probability of such a circuit is given by the per-layer product formula [1, Eq. 54]:

```
S = 1/2^w + (s(R) - 1/2^w) * lambda(L_d) * lambda(L_{d-1}) * ... * lambda(L_1)
```

where `lambda(L)` depends on the error rates of gates within layer `L` [1, Eq. 55]. Since each `lambda(L_i)` is computed independently per layer, reordering which independently sampled layer occupies which position in the circuit does not change the expected success probability. The product is commutative.

The swap and borrowing operations only change which independently sampled Clifford layer sits at the outermost position. They do not alter the set of layers in the circuit, nor do they break the mirror structure. The theoretical predictions from Eq. 54 remain valid.

## 5. Behaviour Across All Samplers

### 5.1 `NewSampler` --- Primary Target

`NewSampler` (`sampling_utils.py:520-616`) deterministically alternates between 1q-only (even) and 2q (odd) layers. This strict alternation is what causes the parity problem: the deepest layer's type depends on `(k - 1) % 2`, which varies with circuit length.

**Block 1 (swap):** For circuits with `k >= 2` Clifford layers, adjacent layers at indices 1 and 3 always differ in type (one is 1q, the other is 2q). The swap selects which type sits at the outermost position based on round parity.

**Block 2 (borrowing):** For `k = 1` (length-2 circuits), the single layer is always 1q. On odd rounds, a 2q layer is borrowed from a sibling. This ensures the entangling angle is applied to actual CX gates.

### 5.2 `EdgeGrabSampler` --- Statistically Neutral

`EdgeGrabSampler` (`sampling_utils.py:260-482`) places 2q gates probabilistically on every layer with the same density parameter. Every layer has the same expected gate composition.

**Block 1 (swap):** When `has_2q != want_2q`, a swap occurs. But since adjacent layers are drawn from the same probabilistic distribution, swapping two such layers is statistically equivalent to not swapping. The expected distribution of `_pairs` across rounds is unchanged.

**Block 2 (borrowing):** Length-2 circuits from `EdgeGrabSampler` may or may not contain 2q gates (probabilistic). On odd rounds where the single layer happens to be 1q-only, borrowing from a sibling provides 2q gates. This is a minor correction that slightly increases the consistency of entangling angle injection, without altering the statistical properties of the benchmark.

### 5.3 `MatchingSampler` --- Statistically Neutral

`MatchingSampler` (`sampling_utils.py:485-518`) inherits `EdgeGrabSampler`'s `__call__()` method and differs only in edge selection (maximum-weight matching vs. random greedy). The analysis for `EdgeGrabSampler` applies identically.

### 5.4 Standard Mirror RB (Non-QA)

When `initial_entangling_angle = 0.0` and `final_entangling_angle = 0.0` (the defaults for `MirrorRB`), `any(self._angles)` evaluates to `False`. Both blocks are skipped entirely. Standard Mirror RB is completely unaffected.

### 5.5 `full_sampling` Mode

Both blocks are guarded by `not self.experiment_options.full_sampling`. When `full_sampling=True`, each circuit length is independently sampled (no truncation, no reordering), and neither block executes.

## 7. Summary of Changes

### Before (lines 381--392 only):

After truncation, the Clifford reordering places the deepest layer at index 1. For `NewSampler`, the type of this layer (1q or 2q) depends on the circuit length, causing an unpredictable parity pattern across rounds.

### After (lines 381--430):

Three steps execute in sequence:

1. **Reordering** (existing, lines 381--392): Reverses Clifford order so the deepest layer is at index 1.
2. **Parity swap** (new, lines 394--406): For circuits with 2+ Clifford layers, swaps indices 1 and 3 (and their mirrors) when the outermost layer's 2q content does not match the round parity.
3. **Sibling borrowing** (new, lines 408--430): For length-2 circuits on odd rounds, borrows a 2q layer and its inverse from a sibling sequence in the same sample.

The result is a strict invariant: **even rounds have 1q-only outermost layers; odd rounds have 2q outermost layers.** This holds for all circuit lengths, all samplers, and all sample boundaries.
